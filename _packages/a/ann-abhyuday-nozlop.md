# Nozlop

A fast static and fuzzy text checker to aid LLM-agents in writing technical documentation without insulting the intelligence of the (human) reader. Written in Zig while following tigerstyle.

## Installation

Add to your `build.zig.zon`:

```zig
.dependencies = .{
    .Nozlop = .{
        .url = "https://github.com/Ann-Abhyuday/Nozlop/archive/refs/heads/main.tar.gz",
    },
},
```
